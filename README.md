## Hosting

GitHub Pages serves the static files from the root of the `main` branch. The `.nojekyll` file disables Jekyll processing. No application server or credentials are required.

To preview locally, open `index.html` in a browser. To update the website, commit updated HTML, CSS, JavaScript and assets to `main`.
