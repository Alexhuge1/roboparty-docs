# RoboParty RP1 Documentation

RP1 product documentation, hardware references, deployment guides and learning resources.

The 2026-10-12 edition incorporates the supplied RP1 Technical Report v0.8.12: 60 figures with captions and original-page links, a complete 78-page PDF, dedicated mechanical, actuator, dexterous-hand and PartyOS chapters, and 18 reliability method drafts. Images open in an accessible large-image viewer, and search includes chapter contents. Simulation settings, nominal product specifications, research benchmarks and RP1 demonstrations retain their source context.

Website: https://alexhuge1.github.io/roboparty-docs/

## Source Materials

Product material and media originate from [Roboparty/rptest_repo](https://github.com/Roboparty/rptest_repo) and the module repositories linked in the documentation. Their copyright and applicable licenses remain with their respective owners. Repository links that require access retain their original permissions.

Technical-report figures retain their original numbering. The report contains the original references and attribution; `assets/report/figures.json` records page and image provenance. Test durations and environmental conditions are method drafts, not completed performance or reliability results.

## Hosting

GitHub Pages serves the static files from the root of the `main` branch. The `.nojekyll` file disables Jekyll processing. No application server or credentials are required.

To preview locally, open `index.html` in a browser. To update the website, commit updated HTML, CSS, JavaScript and assets to `main`.
